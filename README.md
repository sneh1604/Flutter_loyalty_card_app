# 📇 Loyalty Cards Manager App

A beautifully designed **Flutter app** to manage your loyalty cards — track usage, add cards manually or via code, view statistics, and enjoy a smooth modern UI. This app uses **Flutter Bloc** for state management and is built with scalability and user experience in mind.

---

## 🧰 Features

- 🔄 **Dashboard** – View and manage all your active and used loyalty cards.
- 📈 **Statistics Page** – See how many cards are used vs. still active.
- 🃏 **Card Grid View** – Interactive card layout with swipe-to-delete and tap-to-view.
- ➕ **Add Card Options**:
  - From code *(placeholder for future QR/Barcode feature)*
  - Manually with optional expiry date and image upload
- 📅 **Expiry Date Picker** – Easily select expiration dates.
- 📸 **Image Picker** – Upload a card image via camera or gallery.
- 🧾 **Card Details Page** – View full card details on tap.
- 🧹 **Swipe to Delete** – Remove cards directly from the dashboard.
- 📊 **State Management** using `flutter_bloc`.

---
